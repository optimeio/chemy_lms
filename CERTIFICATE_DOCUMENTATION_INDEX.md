## 🚀 Quick Start Commands

### Start Application
```bash
cd c:\Users\thara\chemy_lms
npm start
```

### Test Certificate Flow
1. Login to http://localhost:5175
2. Complete a course
3. Pass quizzes
4. Click "Download Certificate"
5. Verify PNG downloads
6. Check backend logs

### Test API
```bash
# Save certificate
curl -X POST http://localhost:5002/api/certificates/save \
  -H "Content-Type: application/json" \
  -d '{"userEmail":"test@example.com","userName":"Test","courseId":"123","courseTitle":"Course"}'

# Get certificates
curl http://localhost:5002/api/certificates/user/test@example.com
```
